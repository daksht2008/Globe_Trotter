# Phase 1 — Foundation

This directory contains the complete Phase 1 Foundation:
- Database models (User, Trip, City, Stop, Activity, StopActivity)
- App factory pattern with JWT, CORS, and SQLite setup
- Database seeding with Faker (20 cities, 50 activities)
- Stub API endpoints returning 501 Not Implemented
- Dockerfile and docker-compose.yml setup
- Health check endpoint `/api/health`
