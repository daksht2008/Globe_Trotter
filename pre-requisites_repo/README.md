- **Backend**: Python 3.14+, Flask, Flask-SQLAlchemy, Flask-CORS
- **Database**: SQLite 3
- **Frontend**: React (JavaScript) powered by Vite
- **Containerization**: Docker & Docker Compose (with WSL 2 on Windows)
- **API Communication**: REST / JSON / Axios
